# Predicting-bearing-degradation-from-run-to-failure-data-via-supervised-learning
Abstract—Rolling element bearing degradation is a primary cause of unexpected downtime in industrial machinery. This study proposes a supervised machine learning framework for multi-state bearing health classification using time-domain vibration telemetry from the NASA IMS Dataset 1. Statistical features Standard Deviation, RMS, Maximum Peak, and Kurtosis were extracted across an 8-channel sensor array, while Mean was excluded due to its lack of diagnostic sensitivity. A sensor-specific partitioning scheme categorized the operational lifespan into Normal (Class 1), Warning (Class 2), and Critical (Class 3) states. To resolve severe class imbalance, an ensemble RUSBoosted Trees model was trained using 5-fold cross-validation and a custom misclassification cost matrix. The framework achieved class-balanced True Positive Rates (TPR) of 91.0% (Normal), 83.6% (Warning), and 95.6% (Critical). Crucially, it eliminated high-risk critical-to-normal false negatives (0.0% error rate), demonstrating high reliability for safety-critical predictive maintenance systems
